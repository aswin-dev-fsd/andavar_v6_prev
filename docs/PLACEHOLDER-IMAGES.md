# Placeholder images ledger

Tracks every temporary/stock image used in the build, so each can be swapped
for real Shri Andavar photography later. Nothing should be added here without
your approval first (source, filename, size).

## Home page

No placeholder photos were used. The hero and other visuals use abstract
gradient shapes and line-drawn SVG (aperture rings, icons) instead of
photography, matching the reference site's own hero treatment. Nothing to
swap out on this page.

## Pages not yet built

When a page needs a real photo (e.g. the surgeon's portrait on
`our-surgeon.html`, or facility photos on `about.html`), it will be recorded
here with:

- File path in the project
- Source / license
- What it's standing in for
- What real asset should replace it
